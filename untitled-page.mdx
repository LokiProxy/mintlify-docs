title: "API 使用指南"
---

以下路徑均以您的服務地址為前綴。先取得訪問令牌，再通過`Authorization`請求頭會調用其他接口。請妥善保管帳號密碼和令牌；再次取得令牌後，舊令牌將失效。

## 1.取得訪問令牌

`POST /wapi/token/`，請求體為 JSON：

```http
Content-Type: application/json
```

```json
{
  "username": "your_email@example.com",
  "passwd": "your_password"
}
```

成功時，回應的`results.token`即為訪問令牌：

```json
{
  "code": 200,

}
```

購買過動態 GB、優質動態 GB 套餐或兌換過動態流量的帳號可取得令牌。此接口有訪問頻率限制，收到 HTTP 429 時請稍後重試。

## 3.檢查優質動態 GB 流量消耗

`GET /wapi/consume/premium/chart/`

請求頭、查詢參數及回應格式與動態 GB 流量消耗接口相同。示例：`GET /wapi/consume/premium/chart/?suname=sub_account&st=1735689600&et=1735776000`。

曾購買優質動態 GB 套餐的帳號可調用此接口。

兩個流量接口均遵循以下時間與返回規則：

- `st`、`et`任一未提供或不大於 0 時，查詢帳號時區的當天零點至當前時間。
- `st` 与 `et`相同時，查詢從該時間起的一天；開始時間晚於結束時間將返回參數錯誤。
- `results`按時間順序排列的數據點；`period`是時間段，`timestamp`是對應的 Unix 秒，`total_traffic_count`是該時間段消耗的流量（字节）。無消耗的時間段回傳 0。

響應示意（數值僅用於說明格式）：

```json
{
  "code": 200,
  "message": "success.",
  "results": [
    {
      "period": "2025-01-01T00:00:00Z",
      "timestamp": 1735689600,
      "total_traffic_count": 1048576
    }
  ]
}
```

## 4.批量創建兌換碼（CDK）

`POST /wapi/cdk/create/`

```http
Content-Type: application/json
Authorization: Bearer YOUR_TOKEN
```

    </tr>
  </tbody>

動態流量兌換碼範例：

```json
{
  "cdk_type": 1,
  "flow": 10,
  "day": 30,
  "num": 2
}
```

成功時，`results`是生成的兌換碼列表；其中`Cdk`是兌換碼，`Type`是類型，`Flow`是字节数，`Ip`是 IP 數量，`Days`是有效天數：

```json
{
  "code": 200,
  "results": [
    { "Cdk": "EXAMPLE1", "Type": 1, "Flow": 10000000000, "Ip": 0, "Days": 30 }
  ]
}
```

請確保帳戶擁有足夠的對應資源；資源不足時整批創建會失敗。請勿同時提交相同的創建請求。此接口有訪問頻率限制，收到 HTTP 429 時請稍後重試。
