<AccordionGroup>
  <Accordion title="**Q1：How do I use the Short-Term Residential IP plan?**">
    To use the short-term residential IP plan, you can download and install our client app and obtain IPs through port forwarding. Alternatively, log in to the LokiProxy dashboard and access the service via API or authentication.
  </Accordion>

  <Accordion title="**Q2：Where can I get the IP list?**">
    You can access the full IP list via the [LokiProxy](https://dashboard.lokiproxy.com/proxy/residential-ip) dashboard or by downloading the LokiProxy client app. You can filter proxies by country, state, or city to precisely locate the IPs you need.
  </Accordion>

  <Accordion title="**Q3：How long can an IP stay active?**">
    For residential IPs, the duration varies by IP. From the moment you start using it until the IP naturally goes offline, the connection remains stable. If an IP goes offline and later comes back online, you can reuse it for free within the 24-hour list.
  </Accordion>

  <Accordion title="**Q4：Can I reuse extracted proxies?**">
    Yes. Any proxy you have extracted can be reused for free within 24 hours via the “24-hour list” in the dashboard.
  </Accordion>

  <Accordion title="**Q5：Do unused IP credits expire?**">
    No. Unused IP credits never expire. Your balance is only deducted when you extract an IP for the first time.
  </Accordion>

  <Accordion title="**Q6：What are the advantages of Lokiproxy's Short-term Residential IP Premium Plan?**">
    ●Supports CDKey allocation: Easily distribute usage within your team for clearer permission management.

    ●Resale rights included: Premium Plan users enjoy the right to resell IP resources, allowing flexible monetization of idle quota.
  </Accordion>

  <Accordion title="**Q7：How to use the Short-term Residential IP Premium Plan?**">
    You can purchase the corresponding package based on your needs and usage. Then, go to the Dashboard - Short-term Residential IP - CDKey, generate a CDKey according to the number of IPs you want to use, and redeem it on the proxy settings page to start using.
  </Accordion>
</AccordionGroup>
