Before using IPv6 proxies, please confirm that you have purchased a corresponding plan. If you haven't purchased one yet or need to add more, click "[IPv6 Proxy](https://dashboard.lokiproxy.com/proxy/ipv6)" to complete your purchase.

**Tips:**

<Info>
  After purchasing IPv6 proxies, you can view them under Dashboard > IPv6 Proxy > Available IPs.
</Info>

<Info>
  When an IP expires, your available IP count will decrease accordingly.
</Info>

<Info>
  Each IP comes with dedicated bandwidth, which you can select and upgrade as needed. IPs are renewable for worry-free long-term use.
</Info>

## **Steps:**

1. Go to Dashboard - "IPv6 Proxy"
2. Check your available IP count on the "Set Up" page, which shows the number of IPs remaining for export.

<Tip>
  Note: If the available IP count is 0, click "Recharge" to select and purchase the country, bandwidth, and IP quantity you need.
</Tip>

![1 12](/images/1-12.png "1 12")

3. Select the IP address you want to use, then paste the copied "Proxy Command" into your application or tool to complete the setup.

<Tip>
  Note: If you're using a large number of IPs, check the addresses you need and click "Export" for easy storage and management.
</Tip>

![2 11](/images/2-11.png "2 11")

## How to Upgrade Bandwidth?

You can flexibly choose single-IP upgrade or batch bandwidth upgrade based on your actual needs.

**Single-IP Upgrade:**

1. Select the IPv6 address you want to upgrade, then click "Bandwidth Upgrade ."

![3 8](/images/3-8.png "3 8")

2. Click the dropdown menu, select the bandwidth cap you want to upgrade to (up to 50Mbps), then click "Confirm."

![4 7](/images/4-7.png "4 7")

**Batch Upgrade:**

1. Check "IPv6 Address," then click "Batch Bandwidth Upgrade."

<Tip>
  Note: "Batch Bandwidth Upgrade" only supports bulk upgrades for IPv6 addresses displayed on the current page. If you need to upgrade more addresses, simply repeat this operation.
</Tip>

![5 7](/images/5-7.png "5 7")

2. You can upgrade the desired bandwidth cap for each IPv6 address individually. Once confirmed, click "Confirm."

![6 4](/images/6-4.png "6 4")
