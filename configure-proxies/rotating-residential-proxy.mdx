Before configuring residential proxies, please ensure you have added allowlisted IPs or sub-users.

## **Accessing Proxies via API**

1. Go to Dashboard - **\[Rotating Residential/ High-Purity Residential\]**
2. Choose **“API (IP Whitelist)”** and click **“Proxy Setup”**

<Frame>
  ![11 2](/images/11-2.png "11 2")
</Frame>

3. Select the desired country/region or opt for **“Global Mix”**
4. Decide whether to enable the **ASN** configuration feature based on your actual needs.
5. Enter the number of Proxies to extract (up to 900)Configure as needed: **“Protocol Type”**, **“Format”**, **“Separator”**, and **“Session Type”**
6. Select a **“Hostname”**. For optimal connectivity, choose the server closest to your network IP address
7. Click **“Generate API URL”** to display the link in the **“Get API URL”** section on the right

<Frame>
  ![22](/images/22.png "22")
</Frame>

8. Click **“Open URL”** to view the available proxy list

<Frame>
  ![33](/images/33.png "33")
</Frame>

## **Accessing Proxies via Username/Password**

1. Go to Dashboard - **\[Rotating Residential/ High-Purity Residential\]**
2. Choose **“Username:Password”** and click **“Proxy Setup”**

<Frame>
  ![44](/images/44.png "44")
</Frame>

3. Select your desired country/region, state-city, or choose random
4. Decide whether to enable the **ASN** configuration feature based on your actual needs
5. Choose a **“Session Type”**:

<Check>
  **“Rotating IP”**: Changes IP with each request
</Check>

<Check>
  **“Sticky IP”**: Allows setting a specific IP duration
</Check>

6. Select a **“Hostname”**. For the best connection, choose the server nearest to your network IP address
7. Select the **“Sub-user”** for proxy access

<Frame>
  ![55](/images/55.png "55")
</Frame>

8. Finally, choose the number of proxies and format in the right panel, then click **“Generate URL”** to get the available proxy list in the **“Proxy Generator”.**

<Frame>
  ![66](/images/66.png "66")
</Frame>
