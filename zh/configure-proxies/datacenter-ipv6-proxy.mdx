---
title: "如何使用數據中心IPv6代理？"
sidebarTitle: "IPv6代理"
---

使用 IPv6 代理前，請確認您已購買相應套餐。若尚未購買或需補充，可點擊「[IPv6 代理](https://dashboard.lokiproxy.com/zh-TW/proxy/ipv6)」完成購買。

**溫馨提示：**

<Info>
  购买 IPv6 代理後，您可前往 儀表板 > IPv6 代理 > 可用 IP 查看。
</Info>

<Info>
  IP到期後，您的可用IP會相應減少。
</Info>

<Info>
  本服務每個 IP 配備獨立帶寬，您可按需選擇、升級；IP 支援續期，長期使用更省心。
</Info>

**使用步驟：**

1. 進入儀錶板 - 「IPv6 代理」

2. 在「設置代理」介面查看您的可用IP數量，此處顯示您目前剩餘可導出的IP數量。

<Tip>
  注意：若可用 IP 數量為 0，點擊「充值」，即可選擇並購買所需的國家、帶寬及 IP 數量。
</Tip>

![1 7](/images/1-7.png "1 7")

3. 選擇你要使用的IP地址，將複製好的「代理命令」粘貼至應用程式或工具中，即可完成配置。

<Tip>
  注意：若使用的IP數量較多，可勾選所需地址後點擊「導出」，方便統一儲存與管理。
</Tip>
