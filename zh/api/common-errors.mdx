title: "常見錯誤"
---

| `code` | **含義** |
| :-: | :-: |
| `41001` | 查詢參數錯誤，或指定的子帳戶不存在 |
| `41003` | 帳號或密碼錯誤 |
| `41005` | 當前帳號不具備相應接口的使用資格 |
| `41010` | 令牌無效（HTTP 403） |
| `40049` | 創建兌換碼的參數不合法 |
| `40052` | 創建兌換碼失敗，例如對應資源不足 |
| `40901` | 相同的創建請求正在處理中 |

<Tip>
  請同時檢查回應中的 `code`：部分業務錯誤會以 HTTP 200 回傳。
</Tip>
